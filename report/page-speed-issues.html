Critical Issue

Page Speed & User Experience

Video autoplay functionality is negatively impacting SEO performance and degrading Core Web Vitals metrics.

Site-Specific Observations

Issue Priority Rationale
Video Autoplay with Sound Critical Autoplaying video with sound degrades user experience — users may leave immediately, increasing bounce rate. It also consumes bandwidth and slows page load, hurting LCP and INP scores.

SEO Impact of Autoplay

Google's Core Web Vitals assessment penalizes pages with high Cumulative Layout Shift (CLS) and poor Largest Contentful Paint (LCP). Videos that autoplay with sound often load large media files that delay LCP, and autoplay behavior can increase bounce rates, which is a negative user experience signal.

Recommendations

1

Disable Video Autoplay Entirely

Remove the autoplay attribute from video embeds. Let users choose to play videos when they want. This reduces initial page load size and improves LCP.

2

Use Muted Autoplay as Fallback

If autoplay is essential for design purposes, ensure all videos use the muted attribute. Modern browsers block autoplay with sound, but muted autoplay is allowed and less intrusive to users.

3

Lazy Load Video Embeds

Use lazy loading for videos below the fold. This ensures above-the-fold content loads quickly while videos further down the page load only when they enter the viewport.

Code Example: Muted Autoplay

<video autoplay muted loop playsinline>
  <source src="hero-video.mp4" type="video/mp4">
</video>

Adding muted and playsinline ensures the video autoplays without sound and works correctly on mobile devices.
